# JavaScript介绍
## 为什么学习 JavaScript?
JavaScript 是 web 开发人员必须学习的 3 门语言中的一门：
 1. HTML 定义了网页的内容
 2. CSS 描述了网页的布局
 3. JavaScript 控制了网页的行为
## JavaScript 是脚本语言
 - JavaScript 是一种轻量级的编程语言。
 - JavaScript 是可插入 HTML 页面的编程代码。
 - JavaScript 插入 HTML 页面后，可由所有的现代浏览器执行。
